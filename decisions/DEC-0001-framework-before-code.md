# DEC-0001 — Build the framework before any code, and scope this log against `prd.md` §12

**Status:** DECIDED
**Date:** 2026-08-30
**Decided by:** Stakeholder
**Affects:** everything

## Problem
Two questions at once. First: with a complete PRD in hand, is the next artefact code or
process? Second: `prd.md` §12 already carries ~25 settled product decisions in a table. If
this directory also carries them, they exist twice and will drift.

## Constraints
- The stakeholder directed: *"build the framework not the code first."*
- Code is to be generated by many short, bounded agent sessions. Such a session decides
  nothing and reads only what it is given, so every constraint it must honour has to exist as
  a file before it starts.
- `prd.md` §12 is authoritative for product decisions and is explicitly closed.
- Duplication across two logs guarantees divergence, and a divergent decision log is worse
  than none, because it is consulted.

## Options
1. **Code first, process as it emerges.** Fast to a first commit; every early module is
   written before its guards exist, so the guards then find violations in code with dependents.
2. **Framework first; this log holds only new decisions and points at §12 for settled ones.**
3. **Framework first; port §12 into ~25 records here.** Uniform format, at the cost of two
   copies of every product decision.

## Decision
Option 2. This deliverable is the framework: `CLAUDE.md`, the DDD analysis, the architecture
and stack, the decomposition and roadmap, the process documents, and this log. No source code.

This log holds **engineering and process decisions** — the ones `prd.md` did not settle.
`prd.md` §12 remains the sole record of product decisions, referenced from here and never
copied. `decisions/INDEX.md` links both.

## Expected result
A subagent can be given a task spec plus `CLAUDE.md` and produce conforming code without
conversational context. If a session has to ask what the rules are, this deliverable failed.

## Reopens if
A product decision from §12 needs restating because it acquired engineering consequences the
PRD could not have anticipated. Then a record here **references** it and adds the consequence —
it never restates the decision.

## Consequences accepted
Two documents must be read to see all decisions. Accepted: one copy of each is worth more than
one place to look.
