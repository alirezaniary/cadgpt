# Decisions

Append-only. One short entry per settled decision — what, why, and what would reopen it.
A decision reached in conversation and not written here did not happen and will be re-litigated.

---

## Inherit the IFC/IDS toolchain; do not rebuild it

`ifcopenshell` parses IFC. `ifctester` evaluates buildingSMART IDS rule files against a model
and ships `Html`, `Json`, `Bcf`, `Ods`, `Console`, and `Txt` reporters. The report this product
returns is generated by inherited code, not ours. Our residue is admission, normalization,
storage, tenancy, and presentation.

**Verified 2026-09-01**, not assumed: `ifcopenshell 0.8.5` + `ifctester 0.8.5` checked a 47MB
real IFC (Schependomlaan) against the Dutch BIM Basis ILS national standard, and against a
hand-written numeric rule, producing correct pass/fail counts with per-entity reasons and
GlobalIds.

**Reopens if:** `ifctester` cannot express a facet a real rule set needs.

## Rules are data; the product ships no building code

The app is jurisdiction-agnostic. A jurisdiction is a set of loaded IDS files and nothing else.
Iranian building code translation is explicitly out of scope for the MVP — the goal is that any
IDS you hand it works.

**Reopens if:** never. This is the product.

## Three-valued results are the value-add over raw `ifctester`

`PASS | FAIL | INDETERMINATE`. `INDETERMINATE` never becomes `PASS` in any count or summary.

This is not theory. A "minimum 900mm door width" rule run against Schependomlaan on 2026-09-01
reported **113 failures**. Only **12** doors are actually too narrow; the other **101 have no
width recorded at all**. `ifctester` reports "attribute missing" and "attribute violates the
rule" both as `FAIL`. Conflating them tells an architect they have 113 code violations when
they have 12 violations and 101 unknowns. Separating them is the product.

**Reopens if:** never.

## The MVP evaluates synchronously; no queue yet

A 47MB model completes in 9.9s end to end (4.4s parse, 1.2s validate). That fits inside an
ordinary HTTP request with room to spare. Celery, RabbitMQ, and Redis are not in the MVP.

**Reopens if:** measured evaluation time approaches the request timeout, or concurrent users
make a web worker per review untenable.

## Web app, Django, server-rendered first

Django + DRF for the backend. Server-rendered templates for the first UI — React and Vite are a
reasonable later choice but are not needed to prove the product, and adding them now doubles the
surface before there is a user. Farsi-first, RTL-native, with identifiers and IFC classes in
isolated LTR runs.

**Reopens if:** the interaction genuinely needs client-side state that templates cannot carry.

## No inference client in the evaluation path

The engine package may not import an LLM SDK or an HTTP client. Enforced mechanically by the
import-linter contract in `pyproject.toml`, not by remembering. An LLM may help author rules or
explain a result; it never decides pass or fail.

**Reopens if:** never. This is I1.

## Python 3.12 and uv

Forced by the inherited toolchain, which is Python. One lockfile.

**Reopens if:** never, while the evaluation stack is `ifcopenshell`.

## 2026-09-01 — Reset the repository to the MVP path

**Problem.** 46 commits had produced 13,773 lines of Markdown, a 4,151-line verification
harness, and 976 lines of domain code, none of which touched IFC or IDS. `ifcopenshell` and
`ifctester` were declared dependencies imported by zero lines of source. The single active task
was moving a directory, specified in 1,551 lines, after three previous attempts at that same
move were retired before anyone wrote code.

**Decision.** Reset `main` to `942b45f`, the last commit before the process machinery
compounded, and discard the nine commits after it (~11,000 lines: 21 decision records, a
1,551-line directory-move spec, and role documents for two empty directories). Then strip the
remaining framework — `docs/process/`, `docs/ddd/`, `docs/roadmap/`, `decisions/`, `tools/`,
`src/engine/observation/` — down to `prd.md`, a short `CLAUDE.md`, this log, and a plan.

Nothing from the discarded commits was carried forward. `engine.observation` was imported only
by itself and belongs to the deferred derivation branch; it returns when that branch starts.

**Kept:** the product thinking in `prd.md`, the invariants that survived contact with reality,
and the one guard with teeth — the import contract keeping inference out of the engine.

**Recovery:** `git checkout backup/pre-reset-20260901`.

**Reopens if:** never. Rebuilding the harness before the product it guards is what produced this.
